# Adopt Wibo September feedback for calm headings and a two-page ending

## Decision

Use Wibo van Gennip option 1 from 11 September 2026. Show one calm lowercase heading above each gallery grid. Keep the opening cover and every active tile view image-primary with only the assigned sentence. Split the old combined RUST gateway into a logo-only gateway and a final quote gateway.

The default experience has six screens: nature, quiet moments, relaxed faces, take a breath, calm in the rush, and your calm quote. Counted with the opening cover, that is seven visitor pages. The default logo gateway shows only the logo and its title, vertically centered. The default quote gateway shows no logo, only the quote title and the one-liner form, vertically centered. It uses the short English prompt `What is calm for you?`. Gateway descriptions and links remain configurable for local administration, and a divider appears only when a gateway screen has both links and the one-liner.

## Rejected option

Option 3 would split the old gateway text across two pages and keep both RUST links in the main flow. That keeps too much reading in the flow and risks pulling a relaxed visitor out of the moment. Option 2 would keep links on both gateway pages. Background information can become a separate appendix page later.

## Consequences

Gallery headings are an explicit product requirement, so they are allowed beside the borderless gap-free grid rule. The Pexels and CC0 credit trail stays on the credits page and in the media provenance record. Reset restores the bundled six-screen experience.

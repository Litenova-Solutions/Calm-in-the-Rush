# Use a source-available noncommercial license

## Decision

Litenova Solutions (https://litenova.solutions/)`. Third-party media retains its own license and is
listed in `THIRD_PARTY_NOTICES.md` and `docs/research/media-provenance.md`.

The README calls the project source-available, not open source, because commercial use is restricted.

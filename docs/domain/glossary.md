# Glossary

| Term | Meaning |
| :-- | :-- |
| Experience screen | An ordered Gallery, Breathing, or RUST gateway surface in the phone experience. |
| Gallery screen | An ordered group of image tiles that can use its first pre-filled tile as the opening cover. |
| Pre-filled tile | A tile with bundled or browser-local image media supplied by local administration. |
| Upload tile | A visible slot that accepts one image file in the current browser. |
| Visitor upload | Browser-local image media that occupies an upload tile. |
| Tile sentence | The single administrator-assigned sentence associated with one specific tile and shown when that tile is the opening cover. |
| One-liner | An optional short answer a visitor stores in the current browser. |
| Bundled content | Media shipped with the web demo. |
| Local content | Experience configuration and media blobs stored in the current browser's IndexedDB database. |
| Calm moment | The primary flow from opening the gallery to selecting media. |

# Glossary

| Term            | Meaning                                                                        |
| :-------------- | :----------------------------------------------------------------------------- |
| Scene           | A nature video, its ambient sound label, poster, description, and attribution. |
| Poster          | A still image shown before or instead of video playback.                       |
| Ambient audio   | The sound embedded in a scene video.                                           |
| Bundled content | Media shipped with the web or native application.                              |
| Local content   | Media and metadata stored in the current browser IndexedDB database.           |
| Draft           | A local scene that is not shown in the public demo.                            |
| Published       | A scene eligible for the public demo in sort order.                            |
| Calm moment     | The primary flow from opening a scene through leaving it.                      |

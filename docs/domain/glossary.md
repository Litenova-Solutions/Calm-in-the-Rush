# Glossary

| Term | Meaning |
| :-- | :-- |
| Gallery page | An ordered group of zero or more media tiles in the web phone gallery. |
| Pre-filled tile | A tile with bundled or browser-local image or video media supplied by the gallery editor. |
| Upload tile | An ordered slot that accepts one image or video file in the current browser. |
| Gallery upload | Browser-local image or video media that occupies an upload tile. |
| Bundled content | Media shipped with the web demo. |
| Local content | Gallery configuration and media blobs stored in the current browser's IndexedDB database. |
| Calm moment | The primary flow from opening the gallery to selecting media. |

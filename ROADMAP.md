# Roadmap

## Current demo

- Publish four attributed nature scenes in web and native experiences.
- Keep administration content in the current browser.
- Verify accessibility, content provenance, and privacy boundaries in CI.

## Later work

- Add more media after license review.
- Review localization needs.
- Evaluate a native media cache and a hosted content workflow as separate decisions.

Store publication, accounts, synchronization, analytics, and remote administration are not planned
for this demo.

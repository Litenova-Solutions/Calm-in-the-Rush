# Privacy

Calm in the Rush has no accounts, cookies, analytics, advertising, tracking, location access, microphone access, or camera access.

The web demo stores the visitor's own photos and feedback (how calm they feel and an optional comment) in IndexedDB in the current browser. It keeps the chosen photo and whether the tour and the install prompt were seen in the browser's local storage, and its service worker caches the demo's pages and images so it opens without a connection. It does not send any of this to a server or make it visible to another browser, device, or person. Browser private mode, storage eviction, and cleared site data can remove it. On iPhone and iPad, a demo added to the home screen keeps its own storage, separate from Safari's.

The demo has no share control, server upload, embedded video player, or remote content service.

Report a privacy concern to `info@litenova.solutions`.

# Privacy

Calm in the Rush has no accounts, cookies, analytics, advertising, tracking, location access, microphone access, or camera access.

The web demo stores experience screen configuration, tile-specific sentences, pre-filled image media, selected uploads, an optional visitor one-liner, and the visitor's optional answer on the calm slider (a number from 0 to 100) in IndexedDB in the current browser. It keeps the date until which the install invitation stays hidden in the browser's local storage, and its service worker caches the demo's pages, icons, and still images so an installed demo opens without a connection. It does not send those records to a server or make them visible to another browser, device, or person. Browser private mode, storage eviction, and cleared site data can remove local changes. The administration page shows storage information and has a reset action.

The demo has no share control, server upload, embedded video player, or remote content service.

Report a privacy concern to `info@litenova.solutions`.

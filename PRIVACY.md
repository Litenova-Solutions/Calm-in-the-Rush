# Privacy

Calm in the Rush has no accounts, cookies, analytics, advertising, tracking, location access,
microphone access, or camera access.

The browser administration demo stores scene metadata and uploaded media in IndexedDB on the current
browser. It does not send those files to a server or make them visible to another browser, device, or
person. Browser private mode, storage eviction, and cleared site data can remove local changes. The
administration page shows storage information and has a reset action.

The demo uses Web Share or the clipboard only when a person presses Share. The native app uses the
platform share sheet after a person presses Share.

Report a privacy concern to `info@litenova.solutions`.

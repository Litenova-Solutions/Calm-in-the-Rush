# Privacy

Calm in the Rush has no accounts, cookies, analytics, advertising, tracking, location access, microphone access, or camera access.

The web demo stores gallery page configuration, local sentences, pre-filled image or video media, and selected uploads in IndexedDB in the current browser. It does not send those files to a server or make them visible to another browser, device, or person. Browser private mode, storage eviction, and cleared site data can remove local changes. The administration page shows storage information and has a reset action.

The share control opens the browser share surface or copies the current demo URL. It does not upload gallery media.

Report a privacy concern to `info@litenova.solutions`.
